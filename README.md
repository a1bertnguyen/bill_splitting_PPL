# SplitLang — A Custom Domain-Specific Language (DSL) for Bill Splitting

**Course:** Principles of Programming Languages (VNU-HCM International University — SCSE)  
**Toolchain:** Python 3, ANTLR 4.9.2 (`antlr4-python3-runtime==4.9.2`), SQLite, Tkinter

---

## 1. Overview & Motivation

Splitting group bills (dinners, trips, shared apartments) involves tricky arithmetic: multiple split modes (equal, exact, percentage, weighted ratio), itemized receipts, proportional tax/tip/discount distribution, penny-exact rounding, and minimizing the number of bank transfers.

Instead of relying on a general-purpose LLM (which can miscalculate arithmetic, round inconsistently, or hallucinate balances), **SplitLang** applies core **Principles of Programming Languages (PPL)** concepts to build a **deterministic, local, unit-tested Domain-Specific Language**:

- **Five-Stage Interpreter Pipeline**:
  1. **Input** — Single DSL command or multi-line `.split` script (`main.py` / `cli.py`)
  2. **Lexical Analysis** — `SplitLangLexer.py` (generated by ANTLR 4.9.2 from `SplitLang.g4`)
  3. **Syntax Analysis** — `SplitLangParser.py` + `SplitLangErrorListener` (validates CFG rules, recursive lists, arithmetic operator precedence, and block syntax)
  4. **Visitor & AST Generation** — `module/ASTGeneration.py` & `module/ASTutils.py` (strips syntactic sugar and builds clean `Op` AST nodes)
  5. **Semantic Validation & Action Execution** — `module/utilFunction.py` & `module/Database.py` (`Decimal` math, Largest-Remainder rounding, Greedy Minimum Cash Flow debt simplification, SQLite persistence)

## 2. Project Structure

```text
bill splitting app/
├── main.py                       # Desktop GUI (Console + Balances + Live PPL Inspector)
├── cli.py                        # Interactive REPL & .split script runner
├── controller/
│   └── Response.py               # 5-stage pipeline orchestrator & custom ErrorListener
├── module/
│   ├── ASTGeneration.py          # Custom ANTLR4 Visitor (Parse Tree -> AST Ops)
```

## 3. Quick Start

### Install dependencies
```bash
pip install -r requirements.txt
```

### Run the Desktop GUI (with Live PPL Inspector!)
```bash
python main.py
```
Click **Run Demo Script** to populate a complete group outing, and click the **PPL Inspector (Tokens / Tree / AST)** tab to inspect Stage 2 Tokens, Stage 3 Parse Tree, and Stage 4 AST live.

### Run via CLI / Script Runner
```bash
# Run a script file
python cli.py examples/dinner_demo.split

# Run a script file and display Lexer Tokens, Parse Tree, and AST
python cli.py examples/dinner_demo.split --inspect

# Launch interactive REPL
python cli.py
```

### Regenerate ANTLR4 Parser (after editing `parserAnalyzer/SplitLang.g4`)
```bash
python parserAnalyzer/run.py gen
```

### Run Unit Tests
```bash
pytest -v
```

## 4. SplitLang Grammar Summary

| Category | Example Commands |
|---|---|
| **Group & Currency** | `group "Da Lat Trip"`, `currency VND` (or `USD`, `EUR`, `JPY`, `GBP`, `SGD`) |
| **Members** | `add members alice, bob, charlie, dave`, `remove member dave` |
| **Equal Split** | `alice paid 120k + 30k * 2 for dinner split equally`, `bob paid 180k for coffee excluding dave` |
| **Exact Split** | `bob paid 150k for coffee split exact alice: 60k, bob: 50k, charlie: 40k` |
| **Percentage Split** | `alice paid 1m for hotel split percent alice: 40%, bob: 30%, charlie: 30%` |
| **Ratio Split** | `charlie paid 400k for hotpot split ratio alice: 2, bob: 1, charlie: 1` |
| **Modifiers & Date** | `... with discount 50k with tax 10% with tip 5% on 26-11-2026` |
| **Itemized Bill Block** | `bill "BBQ" paid by alice { item "Beef" 450k for all; item "Tea" 60k for charlie; tax 10%; tip 5% }` |
| **Settlement** | `bob pays alice 100k`, `settle bob to alice 100k`, `settle up` |
| **Queries** | `show members`, `show balances`, `show expenses`, `show summary`, `who owes whom?`, `what is alice's balance?` |
| **Controls** | `undo`, `reset`, `help` |
